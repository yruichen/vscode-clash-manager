# Support

Use [GitHub Issues](https://github.com/yruichen/vscode-clash-manager/issues) for reproducible bugs and focused feature requests. Include the extension version, VS Code version, operating system and whether the target is local or OpenSSH.

Do not post subscription URLs, Controller secrets, SSH credentials, private addresses or raw target output. Use [GitHub private vulnerability reporting](https://github.com/yruichen/vscode-clash-manager/security/advisories/new) for security-sensitive reports.
