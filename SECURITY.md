# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Submit a report through [GitHub private vulnerability reporting](https://github.com/yruichen/vscode-clash-manager/security/advisories/new) with reproduction steps, affected versions and potential impact.

Secrets, subscription URLs and raw target output must not be attached to reports. Redact them before submission.
