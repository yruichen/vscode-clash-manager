## [0.1.0] - 2026-08-04

### Added

- Native VS Code Tree View with proxy lifecycle controls and a persistent status bar indicator.
- Local and OpenSSH target support for `clashctl`.
- Policy groups, node selection, provider-aware latency, subscriptions, connections and rules.
- English and Simplified Chinese localization with English as the default.
- Subscription URL removal, output redaction and SecretStorage-backed Controller credentials.
